# Contributing

Thank you for your interest in this project.

## Development Guidelines

- Keep code clean and readable.
- Follow Django best practices.
- One feature at a time.
- One responsibility per app.
- Write tests for every feature.
- Test features in the browser before marking them complete.
- Update documentation when necessary.

## Before Committing

Make sure:

- All tests pass.
- No unnecessary code remains.
- Documentation is updated if needed.

Run tests:

```bash
python manage.py test
```

## Commit Messages

Examples:

```
Add user authentication

Implement ticket assignment

Fix project permission bug

Improve ticket query performance
```

Use clear and descriptive commit messages.

## Branches

For future collaboration:

```
main
develop
feature/<feature-name>
```

Example:

```
feature/ticket-comments
```

## Reporting Issues

Include:

- Expected behavior
- Actual behavior
- Steps to reproduce
- Screenshots if applicable
